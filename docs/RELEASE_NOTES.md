# LabTrack v1.0.0

Beginner-friendly, AI-assisted C#/.NET 8 WinForms learning project.

- Sample CRUD, search and status filters.
- SQLite persistence with validation and parameterized SQL.
- CSV export with escaping and formula protection.
- 27 passing automated tests and a published-executable UI smoke test.
- Self-contained Windows x64 build; extract the ZIP and run LabTrack.exe.

Package built by GitHub Actions run 35305421367 from implementation commit 1007e40. Later documentation commits add the walkthrough, screenshot and verification record without changing the implementation. Intended for synthetic educational sample data, not clinical use.
